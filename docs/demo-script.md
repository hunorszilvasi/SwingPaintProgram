# 1 perces bemutatóvideó – forgatókönyv

Rögzítsd a teljes alkalmazásablakot, és az alábbi lépések közben hagyd láthatóan a vásznat és az eszköztárat.

| Idő | Lépés |
| --- | --- |
| 0–5 mp | Indítsd el a programot, mutasd meg az üres vásznat és az eszköztárat. |
| 5–20 mp | Rajzolj egy vonalat, egy téglalapot és egy ellipszist. |
| 20–28 mp | Jelöld ki az ellipszist, majd húzd arrébb. |
| 28–32 mp | Változtasd meg a kijelölt ellipszis színét. |
| 32–47 mp | Nyomd meg egymás után ötször a `Ctrl+Z` billentyűkombinációt. |
| 47–56 mp | Nyomd meg egymás után háromszor a `Ctrl+Y` billentyűkombinációt. |
| 56–60 mp | Hagyd láthatóan a visszaállított vásznat. |

Mentsd a felvételt `demo/paint-demo.mp4` néven.
